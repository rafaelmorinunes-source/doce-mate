# Doce Mate Infantil — Loja Virtual

Projeto de expansão da Doce Mate (vestuário infantil, Porto Alegre/RS) do
Instagram + loja física para uma loja virtual própria.

Este repositório **não guarda o código da loja** — a loja roda em WordPress +
WooCommerce na Hostinger. O que está aqui é tudo que você precisa para montar,
lançar e operar: o plano, os passos de configuração, os textos jurídicos
obrigatórios e o modelo de importação de produtos.

## Pastas

- **`docs/`** — o passo a passo completo.
- **`juridico/`** — políticas obrigatórias por lei (CDC, LGPD, Decreto 7.962/2013).
  Revise os campos marcados com `[PREENCHER]` e publique como páginas no site.
- **`produtos/`** — modelo de planilha para cadastrar o catálogo de uma vez só.
